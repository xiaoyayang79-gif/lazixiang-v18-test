辣巷子 V18 獨立測試版
========================

這是可單獨部署的靜態測試頁，刻意不連接 V17，也不連接 Supabase。
它不會建立真實訂單、不會更動正式資料庫。

目前包含：
- 客人點餐測試畫面與示範菜單
- 管理後台測試訂單
- 01–20 取餐器號碼分配
- 號碼會在「取餐器已歸還」按鈕確認後才釋放
- 管理後台「啟用來單聲音」與測試聲音按鈕
- 新測試訂單建立時響鈴一次，並可震動
- 後台每 5 秒重繪；目前尚未連接伺服器訂單
- 測試訂單與取餐器狀態存在這台裝置的瀏覽器 localStorage，不會送到伺服器

部署方式（建議先建立全新的 Vercel Project）：
1. 解壓縮 ZIP。
2. 將 index.html 與 vercel.json 一起放入一個新的 GitHub repository。
3. 在 Vercel 新增 Project，選擇這個新 repository。
4. Deploy 後先只用測試訂單操作，確認聲音與取餐器流程。
5. 不要把此測試專案命名或部署到 V17 原有 Project 上。

重要：
- 菜單目前是示範資料，並非從正式系統自動複製。
- 清除瀏覽器網站資料、換瀏覽器或換裝置，測試資料不會共用。
- 此版尚未連接正式訂單資料庫、會員、真實列印或 LINE。
- 在接正式資料庫之前，必須先核對 V17 資料表、取號 RPC、狀態欄位，並決定「已取餐」與「取餐器已歸還」是否分開管理。不要直接對正式資料庫執行未確認的 SQL。
- 瀏覽器通常要求先由使用者點擊「啟用來單聲音」，才能播放提示音；平板音量也需開啟。
